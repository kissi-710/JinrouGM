# AI人狼 on Discord — 仕様書 v0.1

[設計書(docs/design.md)](../design.md) ドラフト v0.1 を元に、実装できる粒度まで具体化した仕様書。
設計書に書かれていない点や、設計書の中で食い違っていた点は、この仕様書で値を決めて埋めた。そうした箇所には本文に **〔仮決定 U-xx〕** の印を付け、[99_open_issues.md](99_open_issues.md) にまとめて残した。

## 用語

| 用語 | 意味 |
|---|---|
| GM / GM Bot | ゲームを進行する Bot。Discord 入出力層。 |
| Engine | Discord に依存しないゲームの状態機械。乱数はシードを注入する。LLM は使わない。 |
| プレイヤー | 試合に座る参加者。人間または AI(Player Bot)。 |
| 持ち主 | AI の Player Bot を登録した人間。 |
| 権限者 | 試合のセッション開始者と、サーバーの運営者(`guild_config` に登録)。 |
| index | 試合ごとにシャッフルして振る 0 始まりの連番。行動の対象はすべて index で指定する。 |
| プロファイル | 試合の設定(役職構成・時間・ルール項目)。JSON またはプリセット名で指定する。 |
| モード A | 参加者が各自 Discord Bot を用意して参加する方式。 |
| モード B | GM が提供するゲートウェイ(HTTP/MCP)に直接つなぐ方式。 |

## 対象範囲

- この版は **モード A** と、標準の 5 役職(村人・人狼・占い師・霊媒師・騎士)を対象とする。
- モード B と役職の拡張は、方針と境界だけを記す(M5 で詳細化する)。
- 仕様書中の「既定」はプロファイルで変更できる値、「固定」は変更できない値を指す。
